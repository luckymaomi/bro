# 危险品培训结果录入

## 报装

```
危险品培训结果录入
1. 场景：危险品管理系统培训结果要月报；通知已改为三表合一，一张 Excel 一次性导入
2. 能干：摸当月材料 → 按固定映射拼字段 → 复制仓内模板写入 → 出预检/正式表给人核
3. 主人先交：总成绩表 + CAAC飞行员信息导出 + 当轮飞行实力表；口头指定培训类型（初训/复训）与编号
4. 口径：证件号=员工号；日期 yyyy-MM；总成绩/培训结果取总成绩表；有效期跟实力表危险品列；手机/性别取 CAAC
5. 交付名：【飞行部】危险品初训/复训＋编号；预检同名后加（预检）；编号不编造、等主人说
6. 节奏：缺料先列「还缺什么」；齐料再拼表；先预检再定稿；不代登录系统上传
```

## 综述

启动说法包括「危险品培训结果录入」「危险品录入」「危险品一次性导入」「危险品月报填表」。

```
主人，小弟到了。危险品培训结果录入，已就位。
开场先对齐你要交的料：总成绩、CAAC导出、实力表、培训类型（初训/复训）、编号；缺哪件报哪件。
齐了再按仓内模板出表；文件名【飞行部】危险品初训/复训＋编号，预检再加（预检）；不代上传系统。
```

材料未齐只问缺项、不臆造；已齐则直接拼表。编号未给时不瞎编文件名，可先拼表暂存或等编号再落正式预检名。

## 主人需提供（开场必对齐）

加载本 Skill 或开干前，先按下面清单对料；缺一项就点名要，不凭印象凑。

### 一、每期必交（文件）

1. **总成绩表**（首选，一张齐最好）
   1. 用途：姓名、员工号、三分项分、总成绩、培训结果
   2. 至少含列：员工号、姓名、态度评价、任务模拟、考试、评估得分、评估结论
   3. 没有这张表时，改交下面「分项成绩」两张，且须能算出／给出总成绩与培训结果
2. **CAAC 飞行员信息导出**（常用文件名如「CAAC飞行员信息导出×月×日.xlsx」）
   1. 用途：补 **手机号、性别、国籍**（国家二字码由国籍换算，中国→CN）
   2. 至少含列：姓名、手机号码、性别、国籍
   3. 按**姓名**与总成绩表对齐；对不上的人单列待补，不编手机号
3. **当轮飞行实力表**（人员信息最新版）
   1. 用途：取每人「危险品」有效期锚点 → 导入表「有效期截止」取到月，「有效期开始」= 截止往前整 2 年
   2. 至少含：员工号、危险品（日期）
   3. 仓根若已有明确「当轮」实力表且主人说用这张，可不再另丢；否则要路径或文件

### 二、每期口头指定（可不另交文件）

1. **培训类型**：初训／复训，**必须主人说一句**（常见「复训」）；不默认猜；写入表内「培训类型」列，并决定文件名里写「危险品初训」还是「危险品复训」
2. **编号**：危险品培训目录／汇总用编号（例 `20261117012`），**必须主人当轮告知**；不从日期臆造、不沿用上期
3. **考勤情况／课时**：不说则默认「正常」、课时 7；有特殊（全员改课时、考勤另写）要说清
4. **输出目录**：不说则落仓库根或主人指定业务目录；**文件名本身**按下方交付规则拼，不另起旧式「一次性导入_年月」名

### 三、无总成绩表时的替补（二选一，与「总成绩表」互斥）

1. **任务模拟、试卷考核成绩表**：员工号 + 任务模拟 + 考试考核
2. **态度评价表**：员工号 + 态度评价
3. 另须主人给出或确认：**总成绩怎么算／培训结果怎么定**（有现成总成绩表则不必）

### 四、一般不用主人再交（仓内或固定默认）

1. **导入空白模板**：仓内 `assets/危险品录入/培训实施-一次性批量导入模版.xlsx`（及 .xls）
2. **工作单位**：中国南方航空货运有限公司
3. **统一社会信用代码**：91440101MA5D3DHK1J
4. **工作单位类别**：航空公司
5. **证件类型**：个人专属编号；**证件号**＝员工号（通知要求）
6. 单位／信用代码变更时主人再改口，否则沿用

### 五、开场缺料时报法（示例）

```
还缺：1. 总成绩表  2. CAAC飞行员信息导出（要手机号/性别）  3. 培训类型请说一句（初训还是复训）  4. 编号请当轮告知（拼进文件名）
已有：实力表可用仓根××；模板用仓内 assets；部门前缀固定【飞行部】。
```

## 仓内模板

1. 主模板（优先）：`assets/危险品录入/培训实施-一次性批量导入模版.xlsx`
2. 同款 xls 备份：`assets/危险品录入/培训实施-一次性批量导入模版.xls`
3. 写入方式：**复制模板** → 保留第 1 行表头、第 2 行说明（不可删）→ 从第 3 行起写数据。
4. 以后改模板：只替换 `assets/危险品录入/` 下文件，并在本篇记变更日；不要另起一套列名。

### 总成绩校验（可选自检）

当轮若三分项齐全，可核：`评估得分 ≈ 态度×0.1 + 任务模拟×0.3 + 考试×0.6`（与 2026-10 样本一致；与旧三表「随堂×0.1+理论×0.6+实操×0.3」同构）。对不上先报差异，不擅自改评估得分。

## 有效期（系统导入表）

1. 模板格式：`yyyy-MM`（或模板允许的 `yyyy年MM月` / `yyyy/MM`）。**勿手改单元格日期格式**，按文本／普通数字分隔符写入。
2. **截止**：取实力表该人「危险品」日期的年-月（与 9 月实填一致：日截到月）。
3. **开始**：截止月往前整 2 年（例：2028-11 → 2026-11）。
4. 实力表无人／无危险品日期 → 该行待补，不编造。
5. 实力表危险品日如何由培训日重算，听「飞行部培训规则速查」；**本 Skill 填导入表时以实力表已落盘值为准**，不在本篇重算日。

## 作战阶段

| 阶段 | 做什么 | 边界 |
| --- | --- | --- |
| **摸底** | 核人数、员工号对齐、CAAC 命中、实力表危险品有无 | 不写正式交付 |
| **预检拼表** | 复制仓内模板写出预检 xlsx（文件名已含【飞行部】＋初训/复训＋编号＋（预检））；报路径与人数、待补名单 | 不上传系统 |
| **定稿** | 主人确认后去掉文件名中的（预检），或另存为无（预检）的正式名；不改编号与部门前缀 | 仍不代上传 |

## 交付（文件名 · 2026-11 起）

对方汇总要求：文件名带部门，便于按「【飞行部】…」归集。编号由危险品侧／主人当轮给出（培训目录里的编号），**不臆造**。

1. **正式名（定稿）**：`【飞行部】危险品{初训|复训}{编号}.xlsx`  
   例：`【飞行部】危险品初训20261117012.xlsx`、`【飞行部】危险品复训20261117012.xlsx`
2. **预检名**：正式名去掉扩展名前加 `（预检）`  
   例：`【飞行部】危险品复训20261117012（预检）.xlsx`
3. **拼法**：部门前缀固定 `【飞行部】` → `危险品` → 主人指定的初训或复训（与表内培训类型一致）→ 主人给的编号（原文照抄，不增删分隔符）→ 预检阶段再加 `（预检）`。
4. **编号未到**：可先摸底／试拼；落盘预检文件前必须有编号。不得用旧式名 `危险品培训结果_一次性导入_YYYY年M月_预检.xlsx` 冒充本期交付名（除非主人当轮临时改口）。
5. **落点**：仓库根、`危险品录入` 业务目录或主人指定路径；过程脚本可放 `scripts/`（可复用）或 `_tmp/`（当轮一次性）。
6. 聊天只报路径、人数、待补项；不把整表贴进对话。

## 铁律

1. 不臆造培训类型、编号、有效期、姓名、手机。
2. 第 2 行说明永不删除。
3. 证件号只用员工号，不用身份证。
4. 预检与定稿分清；预检文件名必须带（预检）；定稿去掉（预检）。
5. 不登录、不代点危险品航空运输管理系统上传。
