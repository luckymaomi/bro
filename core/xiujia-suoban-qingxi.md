# 休假锁班清洗

## 报装

合集「能做什么」时只取本段；改能力只改本文件。

```
休假锁班清洗
1. 场景：飞行员休假表（各月「×月休假申请」）乱、有合并，要喂给锁班皇帝（新）批量锁班
2. 能干：拆合并、公休／年假公休／飞行员公休／公休假统一 ALV_FD、按备注 birth／birthday 拆段、合成五列总表；另附「清洗备注」页
3. 铁律：每次先问洗哪个月；不代登录、不代点锁班皇帝提交；质疑只列不清项，不臆造员工号／日期
4. 主人先交：当轮飞行员休假表路径；口头点明洗哪一个月（可多月则列名）
5. 节奏：缺料先列「还缺什么」；摸当月四分部实表 → 预检 → 点头或已授权则出表
6. 下游：产出可直接上传 csn2api「锁班皇帝（新）」；模板真源见下方
```

## 综述

启动说法包括「休假锁班清洗」「锁班名单清洗」「休假表洗锁班」「洗成锁班皇帝表」「公休转 ALV_FD」。

```
主人，小弟到了。休假锁班清洗，已就位。
开场先对齐你要交的料：飞行员休假表路径、要洗哪一个月；缺哪件报哪件。
齐了再拆合并、公休类统一 ALV_FD、birthday 拆段，出锁班皇帝五列表。
不代登录、不代点锁班皇帝提交。
```

本 Skill **只做清洗出表**；真正录入／通过锁班走 csn2api 锁班皇帝（新），本篇不代替操作。

## 主人需提供（开场必对齐）

加载本 Skill 或开干前，先按下面清单对料；缺一项就点名要。完全不懂业务也能照清单交。

### 一、每轮必交／必说

1. **飞行员休假表**（常见文件名如 `2026年飞行员休假表.xlsx`）
   1. 用途：读「×月休假申请」四分部并排区，洗成锁班五列
   2. 至少能定位：员工号、姓名、请假类型、开始日期、结束日期、备注
2. **要洗哪一个月**（如「12 月」；可多月则主人点名列表；默认一次一个月）
   1. **必须主人说一句**；不默认猜当前月

### 二、口头或按需

1. **输出路径／文件名**：不说则落主人指定目录或仓库根，并附「清洗备注」页
2. **人员信息表**（休假簿内常有）：重名补号时作辅助；不以本表臆造补号

### 三、材料从哪来（小白指路）

1. **休假申请表**：飞行部各分部汇总的年度／当月休假申请工作簿，不是飞行门户「技术资料导出」，也不是实力表。
2. **锁班空白模板**：仓外常用 `C:\Users\Administrator\Desktop\工作\csn2api模板\通用批量锁班模板.xlsx`，或 csn2api 仓内 `public/template/通用批量锁班模板.xlsx`；主人有现成模板路径可点明，否则按本篇「下游与模板」取。
3. **上传锁班**：主人自行在 csn2api「锁班皇帝（新）」上传；小弟只出清洗表，不代点提交。
4. 本任务**不需要**技术等级／运行资格／CAAC 导出。

### 四、开场缺料时报法（示例）

```
还缺：1. 飞行员休假表路径  2. 要洗哪一个月请说一句（如 12 月）
已有：锁班模板按本篇默认路径（或你另指定）。未点月份、未给路径只问缺项，不写正式产出。
```

## 下游与模板

1. 下游工具：csn2api **锁班皇帝（新）**（`http-lock-entry-helper`）。五列必填：员工号、姓名、锁班类型、开始日期、结束日期。
2. 产出模板（任选其一，内容契约相同）：
   - 仓外常用：`C:\Users\Administrator\Desktop\工作\csn2api模板\通用批量锁班模板.xlsx`
   - csn2api 仓内：`public/template/通用批量锁班模板.xlsx`
3. 产出要求：
   1. Sheet「锁班数据」：表头五行字段；**删除模板自带示例行**（员工号 000000／飞行员那行）；从第 2 行起写清洗后记录。
   2. **标黄**：凡相对源行**不是原样保留**的产出行，整行浅黄底高亮（含：公休类改写成 ALV_FD、备注 birthday 拆段导致日期变化／拆成多行等）。仅日期格式归一（同日写成 YYYY-MM-DD）、仅补齐合并单元格姓名／员工号且类型与起止日未改的，可视为原样，不标黄。
   3. Sheet「类型列表」：可保留模板原有下拉源，不强行改。
   4. 另增 Sheet「清洗备注」：写清本轮月份、源表路径、转换条数、跳过说明行、birthday 拆段、标黄行数、质疑项、交叉核对结论。
4. 锁班皇帝认类型时：可填 `ALV_FD`、`ALV_FD-飞行员公休（订座）` 或门户全称；本 Skill 产出统一写 **`ALV_FD-飞行员公休（订座）`**（与模板类型列表一致）。`ALV_FD` 在门户侧走时间模式 1（连续时段），默认时刻由皇帝处理，本清洗表只出日期。

## 源表结构（已用 2026 年飞行员休假表核实）

样例：`2026年飞行员休假表.xlsx`。

1. 每月一页：`1月休假申请` … `12月休假申请`；另有「人员信息表」（员工号／姓名对照，重名时作辅助，不以本表臆造补号）。
2. 每页 **四个分部横排**，列块固定：

| 分部 | 序号 | 员工号 | 姓名 | 请假类型 | 开始日期 | 结束日期 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 一分部 | A | B | C | D | E | F | I |
| 二分部 | K | L | M | N | O | P | S |
| 三分部 | U | V | W | X | Y | Z | AC |
| 四分部 | AE | AF | AG | AH | AI | AJ | AM |

3. 第 1 行多为分部说明合并区；第 2 行表头；**数据自第 3 行起**。
4. 常见脏法：
   1. **姓名合并**：同一人多段休假时，姓名格跨行合并，下一行姓名单元格为空。
   2. **员工号合并**：偶发与姓名同时合并（如下行员工号格为空）。
   3. **请假类型列**偶发被写入说明句（非类型代码），须跳过或质疑。
   4. 日期可能是 Excel 日期，或 `2026.12.11` 一类文本。
5. 开干前本轮必须 **实读当月页**：核对四块列字母是否仍如上表；若主人改版，以当月实表为准并写进清洗备注，不凭旧记忆硬套。

## 清洗步骤

### 0. 对齐输入

1. **必问**：洗哪一个月（可多月则主人点名列表；默认一次一个月）。
2. **必有**：当轮休假表路径。
3. 未点月份、未给路径：只问缺项；可先只读结构预检，不写正式产出。

### 1. 展开合并（姓名／员工号）

1. 对每个分部数据区：若姓名或员工号单元格落入合并区域，取该合并区 **左上角** 的值填到本行逻辑字段（拆开＝每人每段休假一行都带齐姓名、员工号）。
2. 展开后仍缺员工号或姓名：列入「清洗备注」质疑，**该行不进锁班数据**（不猜号）。
3. 请假类型、开始／结束日期 **不靠合并填空**：类型格为空且无有效类型 → 质疑并跳过；日期空 → 跳过并备注。

### 2. 跳过说明行／垃圾行

下列写入「请假类型」或整行明显是栏尾说明的，**不进锁班数据**，在清洗备注记「已忽略说明行」：

1. 含「标蓝已备注完」「修改与新增请联系」「已完成，停止新增」「有日期改动的请标红」「已备注完」等操作说明。
2. 示例行：员工号 `000000` 或姓名为「飞行员」且备注为「示例」。
3. 四分部／各栏完全空白行。

### 3. 锁班类型归一

1. **公休类 → 一律** `ALV_FD-飞行员公休（订座）`（认准此码）。凡属下列写法都转成这一码（含已是 ALV_FD 的保持／改写成完整标签）：
   - 已是 `ALV_FD`／`ALV_FD-飞行员公休（订座）`
   - `ALV-年假（公休假）`
   - `ALV-年假（ALV_FD-飞行员公休（订座））` 等把年假与 ALV_FD 写在一起的
   - 白话或乱填：含「公休」「年假公休」「飞行员公休」「公休假」（飞行员公休订座覆盖年假公休假与飞行员公休订座；有人错选年假公休假也一律转成 ALV_FD）
2. **其他已是门户代码的类型**（如 `RECU_LVE-健康疗养`、`CHILD_LVE-育儿假`、`MAT_FA_LVE-陪产假` 等）：**原样写入**总表，代码与门户代码保持一致，不改码。
3. 无法对应任何已知代码、又非上述公休白话：列入质疑，默认不进总表。

（不存在「生日假」请假类型口径；生日只通过第 5 步备注 birth／birthday 处理。）

### 4. 日期归一

1. 开始日期、结束日期都归一成 `YYYY-MM-DD`。
2. 支持 Excel 日期序列、`YYYY-MM-DD`／`YYYY/M/D`／`YYYY.M.D`。
3. 结束早于开始、或缺一端：质疑并跳过。

### 5. 备注含 birth／birthday → 拆段（生日当天不锁）

触发：备注（不区分大小写）含 `birthday`／`birth`／`bir`／`Your birthday`。

1. 从备注解析 **日号**（可多天），例如：`16birth`、`06birth`、`5号有birthday`、`12-14是birth`、`10、13birth`。
2. 将日号落到本行开始～结束日期的闭区间内，得到「生日当日」集合（跨月按实际年月匹配；仅写日号时优先落在本段日期内能命中的那天）。
3. **生日当天整日不锁**：从原区间挖掉这些日期后，按连续自然日拆成多段，每段一行，类型／员工号／姓名同原行。
   - 例：请假 1～10 日、备注 5 号有 birthday → 写成两行：`1～4` 与 `6～10`。
   - 例：12～26 日、生日 16 日 → `12～15` 与 `17～26`。
4. 挖空后若某侧为空段则省略；若整段都被生日日覆盖 → 不进锁班数据，备注说明。
5. 备注提到生日／birth 但抽不出可落地的日号：不擅自拆，列入质疑，原行是否锁班听主人。
6. 解析不清：进质疑清单，该行暂不自动拆。

### 6. 合成总表

1. 四分部清洗结果按顺序竖向拼接（一分部 → 二分部 → 三分部 → 四分部）；同分部内保持源表行序。
2. 输出列仅五列：`员工号`｜`姓名`｜`锁班类型`｜`开始日期`｜`结束日期`。
3. 员工号六位文本（前导零保留）。
4. 不写休假天数、锁班状态、源备注到五列表（birthday 与转换说明进「清洗备注」）。

### 7. 清洗备注页（同一 Excel）

至少写清：

1. 源表路径、月份、统计日。
2. 有效输出行数；公休类改写为 ALV_FD 的行数；birthday 拆段条数；跳过说明行／缺号行数。
3. **质疑清单**：缺员工号、类型不明、日期异常、birthday 解析失败、请假类型合并／错位可疑等——只列事实，不编造处理。

## 预检报数（动手前／交表时）

1. 源表当月四分部原始有效行（去空、去示例、去说明行后）。
2. 展开合并后行数。
3. 写入锁班数据行数（含拆段后增加行）。
4. 跳过与质疑件数。
5. 公休类改写件数；标黄行数。

数量异常、大面积缺号、类型列大面积非代码：先报主人，不默写出可上传定稿。

## 交叉核对（出表后必做，再请主人复核）

交表前小弟必须自核一遍，并在「清洗备注」与回话里报结论；**最后仍请主人按文件再核对一遍**，不默认主人已点头。

1. 源表有效行（去空／示例／说明行）与产出行：birthday 拆段会使产出 ≥ 源；无拆段时产出应等于「有效且类型可入表」行数。
2. 抽核：公休改写行——源类型非 ALV_FD 完整标签、产出为 ALV_FD，且该行已标黄。
3. 抽核：birthday 拆段——源一段、产两段（或多段），日期挖掉生日当日，整行标黄。
4. 抽核：疗养等原样行——类型码与起止日与源一致（日期仅格式差），且未标黄。
5. 标黄行数 = 改写类型行 + 拆段产生的行（按本轮定义统计，写进备注）。
6. 回话末尾固定请主人打开产出表复核标黄与质疑清单。

## 与锁班皇帝的边界

1. 本 Skill **不管** Cookie、提交、通过、冲突回查；那是锁班皇帝的事。
2. 皇帝侧：Excel 姓名仅提示用；真正提交姓名以门户校验为准。本清洗仍应尽量带对姓名，便于人对账。
3. 额度提示（`showNonproductionHolidayRulesTips`）不影响本表怎么洗；不在清洗阶段按额度改类型或拆行（备注生日拆段除外）。
