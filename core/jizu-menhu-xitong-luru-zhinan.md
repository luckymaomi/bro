# 机组门户系统录入指南

## 报装

合集「能做什么」时只取本段；改能力只改本文件。

```
机组门户系统录入指南
1. 场景：主人甩录入通知/名单，先拆成「每人要录什么、不要录什么、先核什么」（货航仅 777 机型）
2. 能干：短通知先挂姓名（员工号）+主事项；指定后展开基础包；资格管理三表分清（机型／资质／岗位）；资质表底表见配套模板
3. 铁律：只预检；「人员资格资历」用资质表模板；机型／岗位不进该模板；机型只认 777；表外代码不编
4. 节奏：默认轻量；指定后基础录入；不代点系统
```

## 综述

启动说法包括「机组门户系统录入指南」「门户录入」「资质录入检查」「资质录入检查预提示」「数据录入」。

简短开场：主人说加载本 Skill 且甩短通知时，只回「主人，技能已加载。」然后按「分层输出」出检查句——**默认只补员工号与通知主事项**；**不要**自动堆 RNP／英语／汉语有效期。复杂报务、单飞、机场名单才用长预提示。默认只预检，不代点系统；货航机型范围 777。

| 阶段 | 做什么 | 边界 |
| --- | --- | --- |
| **预检** | 解析通知；默认轻量短句（员工号+主事项）；主人指定开始运行后再套基础资质包 | 不登录、不改飞行门户/天健 |

## 分层输出（短通知）

两层，**禁止跳层**：

1. **轻量（默认）。** 通知只写「发 F 类机长／CAPF」「添加机型／A1／Z 类」等、**未**说开始运行或基础录入时：只出「姓名（员工号）+ 主事项（代码）」；**不**展开 RNP／英语／汉语有效期，**不**抢套基础资质包。
2. **基础录入（须主人指定）。** 主人明确「准备开始运行」「做基础录入」「按可运行基础包检查」「把英语汉语有效期补上」等之后，才把本包展开进括号，并补语言有效期。指定前只备员工号与主资格，等令。

员工号：当轮实力表／花名册／姓名匹配台账；取不到先写姓名，一句问补号。

## 可运行基础资质包（仅「基础录入」层套用）

一个可运行的副驾驶／机长，门户侧最基础资质按本包核。**仅当主人指定开始运行／基础录入后**才写入短句；未指定时本包只作口径备忘，不自动输出。

1. **技术等级。** 副驾驶如 FOA1／FOA2／FOB 等；机长如 CAPZ／CAPB／CAPC／CAPF 等（以通知为准）。
2. **机型资格。** 货航仅 **777**（系统选项常见 77F／77L，通知未点明时写机型资格即可，不臆造 F／L）。
3. **RNP。** 可运行基础项，同步检查／具备。
4. **英语。** 语言资格；写出等级 + 有效期（有当轮 CAAC／语言表时）。
5. **汉语。** 语言资格；写出等级 + 有效期；**有效期字段为空 = 永久有效**（主人口径，勿留空）。

指定后的同步展开口径（通知未写「不添加××」时）：

1. **添加机型资格** → 括号内：机型资格，同步检查 RNP、英语…、汉语…
2. **Z／B／F 类等机长档（CAPZ／CAPB／CAPF 等）** → 括号内：对应代码，同步检查 CAP、机型资格、RNP、英语…、汉语…
3. **A1 类副驾驶／FOA1（及可运行副驾驶档）** → 括号内：同步检查机型资格、RNP、英语…、汉语…；岗位按铁律 A1→S/O（短句可不展开岗位码，除非主人要码）
4. **取消** → 只写取消对象；不臆造取消清单

语言有效期来源：当轮 CAAC 飞行员信息导出，或主人指定的语言／台账表；缺表先问路径，不编日期。

## 录入铁律（来自业务备忘，预提示必套）

套预提示时优先套本节；与通知冲突时以通知例外句为准并写入清单。基础录入层另套「可运行基础资质包」；轻量层不套。

1. **副驾驶录入前。** 核岗位表是否已有 F/O 或 S/O；核资质表 A1/A2。发布岗位：A1 → S/O，A2 → F/O。
2. **A1。** 成为 A1 类副驾驶 → 同步发 **777** 机型资格（通知写「不添加机型资格」则禁止同步，清单写死），并按基础资质包核 RNP／英语／汉语。关键节点（排班/薪水相关）需复核：A1 类副驾驶、Z 类机长、B 类机长、A 类教员。
3. **型别教员。** 资质表侧：分级 B1–B4 对应 **SIMT** 技术级别 1–4；EBT／SC 另码；失效默认齐 CAPT。细则见「资格管理三表」。
4. **改飞行学员。** 岗位 S/S；资质 S/T + 机型组 **777**。
5. **退回副驾驶。** 同步取消 ACAP。A/B 类机长含 ACAP；C/D 类机长需取消 ACAP。
6. **重航划转。** 档案进「人员基本信息」；基地在「人员基地」设基地 CAN、主基地 CSG；非 777 机型划入 → 学员路径（岗位 S/S、资质 S/T、机型组 **777**）；实践考试通过后原机长→Z、原副驾驶→A1。
7. **机型范围。** 本岗录入预提示只覆盖 **777**；不扩展其他机型。人员机型资格菜单里货航常见选项为 **77F / 77L**（以系统当期选项为准）。
8. **人力关注变更（月统计口径，预提示可不展开操作）。** 副驾驶 FOA1/FOB/FOC/FOD，机长 CAPB，教员 CAPTA；Z 类转机型 1 年改装保护期。
9. **不能「随机」（跟随飞机，不是 random）。** 某人做不了随机时，门户侧重点两处：①「人员基本信息」更新**退休日期**；②「人员基地」做**基地延期**。预提示须点名这两步；具体日期以通知／主人为准，不臆造。

## 资格管理三表（写清楚）

机组门户 **资格管理** 侧，日常批量录入常落三张表，**不要混填**：

1. **机型表**＝菜单「人员机型资格」（如 77F／77L）。
2. **资质表**＝菜单「人员资格资历」（FOA1／CAPZ／SIMT／EBT／RNP／EN／CHNL 等）。
3. **岗位表**＝菜单「人员岗位」（如 S/O、F/O、CAP）。

配套工作底表：`templates/门户-人员资格资历录入模板.xlsx`  
**只服务「人员资格资历」（资质表）**。表内「使用说明」「样例数据」全是假名假号；实办用「待录入空白」或清空样例后重填。机型要／不要加：在资质表「参考信息」里提示即可，真正勾选仍去机型表；岗位同理去岗位表。

型别教员补录口径（资质表内）：B1–B4 → 资格代码 **SIMT**、技术级别 **1–4**；**EBT**＝EBT；**SC**＝SC。SIMT／EBT／SC 失效日默认与该人 **CAPT**（型别教员）失效日齐尾，除非主人另定。

## 铁律

0. **默认预检。** 产出是给人看的录入检查清单，不是系统已办结。
1. **不臆造代码。** 本文件「常用映射」没有的，打开 `资质代码` / `特殊机场资格代码` 查；仍无则标「未收录，请主人给码」。
2. **机型只认 777。** 本 Skill 服务货航运行，机型组 / 机型资格默认只有 **777**（B777）。通知写「同步机型资格」「机型组」而未点其他机型 → 一律按 777；若出现非 777 机型字样 → 停，标疑点问主人（默认不录入其他机型）。
3. **报务 ≠ 单飞。** 通讯报务用 E 开头；区域单飞用 R 开头（区域类）。主人口语说「美报/欧报」→ E*；说「北美单飞/欧洲区域」→ R*。不要混挂。
4. **机场落码。** 货航常见机场见下表；有排班/资格码的必须落到 Rxxx（如 RLAX）；表内无 R 码的写出中文+IATA，并标疑点问主人是否另有系统码。只写中文地名不出码（或不出 IATA）不算完成。
5. **例外优先。** 「面试不合格」「不添加机型」「仅恢复××」等否定句，必须在对应人名下写清「不录××」。
6. **一人一行。** 多人通知按人拆开；同一人多资质合并到该人一行；推荐区每人换行，禁止挤行。
7. **不确定先问。** 「北美责任机长」等业务专名若对应额外岗位/专码且表内无专名，先按通知字面拆区域+机场，并单列「是否还有专码/岗位动作」问主人。
8. **连查技能。** 细查字段时读 `core/zizhi-daima.md`、`core/teshu-jichang-zige-daima.md`；副驾驶积分总表另走「副驾驶流转更新」。

## 通知解析步骤

收到主人通知后，按序做：

1. **切块。** 按句号/分隔符拆成独立事件（例：A1 一批；不合格例外；北美责任机长新增；某人恢复全部）。
2. **提人。** 每人姓名（有员工号更好）；多人用顿号、竖线、逗号分隔的，按人拆。
3. **提动作。** 新增 / 恢复 / 取消 / 不添加 / 延期 等。
4. **提资质对象。** 技术等级、报务、单飞区域、机场、机型、「恢复所有」等。
5. **映射代码。** 先查本文件常用表，再查两份代码 Skill。
6. **套铁律。** 先套「录入铁律」；仅当主人已指定开始运行／基础录入时再套「可运行基础资质包」。再套例外句、A1↔机型、岗位、ACAP。
7. **出预提示。** 短通知默认「短句检查输出」轻量层；主人点了基础录入再出展开层；报务／单飞／机场等复杂名单 → 长骨架「原文+推荐+疑点」。

### 竖线名单读法

形如：`甲某欧洲，北美、安克雷奇、洛杉矶丨乙某，北美、洛杉矶`

1. 以 `丨` 或 `|` 分人。
2. 人名后的「欧洲/北美」→ 同时考虑报务 E* 与单飞 R* 是否都要；**通知只写区域地名且场景是「责任机长/单飞」时，默认先挂区域 R* + 机场码；是否加报务 E* 写进疑点问主人**（除非通知明确「报务」或「通讯」）。
3. 机场名 → 机场资格码。

## 短句检查输出（对主人，纯 txt · 短通知）

禁 markdown。开场一行：「主人，技能已加载。」下一行起直接一段检查话，**不要**「原文／推荐／疑点」长骨架，**不要**堆代码百科。按人拆开，分号连接。

### 轻量句式（默认）

`
姓名（员工号）发F类机长（CAPF）；姓名（员工号）添加A1类副驾驶资格（FOA1）；…
`

只写通知主事项 + 员工号；不写 RNP／英语／汉语。

### 基础录入句式（须主人指定后）

`
姓名（员工号）添加××资格（主资格，同步检查机型资格、RNP、英语×级至YYYY-MM-DD、汉语×级永久有效或至YYYY-MM-DD）；…
`

死规矩：

1. **必带员工号。** 有台账就写「姓名（员工号）」；没有先问补号，不编号。
2. **未指定不展开。** 没说开始运行／基础录入，就停在轻量句式。
3. **指定后再补。** 主动作 + 基础资质包 + 英语／汉语等级与有效期；汉语有效期空写「永久有效」；英语有效期空不编，标缺。
4. **取消。** 通知怎么写怎么带；「三类资格」未点名时保持原句，不猜三项。
5. **Skill 样例只用占位名号**；实办可用真名真号，不回写进本文件。

轻量样例（占位）：

`
主人，技能已加载。

甲某（100001）发F类机长（CAPF）；乙某（100002）发F类机长（CAPF）。
`

基础录入样例（占位，仅指定后用）：

`
主人，技能已加载。

甲某（100001）添加机型资格（机型资格，同步检查RNP、英语4级至2027-03-25、汉语6级永久有效）；乙某（100002）添加Z类机长资格（CAPZ，同步检查CAP、机型资格、RNP、英语4级至2029-02-22、汉语6级永久有效）；丙某（100003）添加A1类副驾驶资格（机型资格、RNP、英语4级至2028-10-13、汉语6级永久有效）；丁某（100004）三类资格取消。
`

## 长预提示输出模板（对主人，纯 txt · 复杂名单）

报务／单飞／机场／多例外时用本骨架；短通知不用。

推荐骨架（标题带冒号；可按通知长短增减）：

`
录入检查预提示（预检，未写入系统）

原文：
〔主人通知原文原样粘贴，不改字、不扩写〕

推荐：
姓名（工号）发中文（代码）…
姓名（工号）发中文（代码）…

疑点：
…
…
`

行式口吻（死规矩）：

`
甲某（100001）发A1副驾驶（FOA1）北美报务（EAMA）区域-美洲*（RAMA）
`

即：姓名（工号）+「发」+ 中文名（代码），多项直接连写；例外写进行内（如不添加机型资格）。

格式铁律：

1. 三段标题固定写「原文：」「推荐：」「疑点：」（带冒号）；无疑点可整段省略「疑点：」。
2. 原文与主人当次通知一字不差。
3. 推荐：每人独占一行换行隔开，禁止多人挤同一行；中文在前、代码括后。
4. 疑点：一行一条，不写 1. 2. 序号。
5. 员工号从花名册/台账取；取不到写姓名并疑点补员工号。
6. 责任机长/单飞且通知只写区域地名：推荐默认只出 R* + 机场码；E* 是否加放疑点。
7. 「恢复所有」无清单时：推荐行写「发恢复所有（清单待补）」；不臆造代码。
8. 花名册已有的码不进推荐行。
9. **Skill 正文样例禁止写真实姓名/真实员工号**；只用甲某、乙某等占位。对主人当次实办可用花名册真名真号，但不回写进本文件。
